# Growth & Backlink Playbook

On-page SEO is handled in code (see `docs/seo.md`). **Ranking and traffic come
from authority + content**, which is off-site work. This doc is the execution
plan plus ready-to-paste copy. Work top-to-bottom; the order is by ROI.

Canonical facts to reuse everywhere (keep consistent — NAP/brand consistency is
itself a ranking signal):

- **Name:** myastro360
- **URL:** https://www.myastro360.com
- **One-liner:** Instant, personalized Vedic astrology — free Kundli,
  horoscopes, Kundli matching, palmistry, numerology, tarot, panchang & muhurat,
  in 12 Indian languages.
- **Categories:** Astrologer / Astrology service / Spiritual

---

## Part A — Off-site action checklist (do in this order)

### 1. Foundations (week 1)
- [ ] **Google Business Profile** — create + verify (`business.google.com`).
      A verified profile can rank in Maps/“near me” and adds a strong branded
      entity. Use the description in Part B. Add the website link, categories,
      logo, and 5+ photos.
- [ ] **Bing Places** — mirror of GBP (`bingplaces.com`); import from Google.
- [ ] **Confirm indexing prerequisites** — sitemap submitted in GSC, `site:`
      starting to populate (see `docs/seo.md`).

### 2. Authority directories (week 1–2) — each is a backlink + a citation
Submit the one-liner + URL to:
- [ ] **Product Hunt** (launch — use the blurb in Part B; pick a Tue–Thu)
- [ ] **Crunchbase** (company profile)
- [ ] **LinkedIn Company Page** (+ post the launch)
- [ ] **G2 / Capterra** (SaaS listings; “Astrology software”)
- [ ] **Justdial, Sulekha** (India local — high relevance for astrology)
- [ ] **AlternativeTo** (vs. AstroSage / AstroTalk)
- [ ] **App directories** if/when the mobile apps ship (Play/App Store listings
      are themselves strong links)

### 3. Social profiles (week 2) — each profile links the domain + builds brand
Create and link the site in the bio for:
- [ ] **Pinterest** (huge for astrology — pin daily horoscope/panchang graphics)
- [ ] **YouTube** (shorts: “your sign today”, “what is panchang”)
- [ ] **Instagram** (daily horoscope cards → link in bio)
- [ ] **Quora** (answer kundli/horoscope questions, link where genuinely useful)
- [ ] **Reddit** (`r/astrology`, `r/Vedicastrology` — participate, don’t spam)
- [ ] **X/Twitter**

> Pinterest + YouTube drive the most *sustained* astrology traffic; prioritize
> them. Quora/Reddit answers can rank and refer for years — answer real
> questions, link only when it adds value.

### 4. Content & outreach (ongoing — the compounding part)
- [ ] Keep the daily horoscope/panchang ISR fresh (freshness signal).
- [ ] Add unique written depth to localized landing pages (city × language).
- [ ] Guest posts / partnerships with Indian astrology + lifestyle blogs
      (use the outreach templates in Part B).
- [ ] Earn mentions: HARO/Qwoted (respond to journalist queries on astrology),
      “best astrology apps” roundup outreach.

### 5. Measure
- [ ] GSC **Performance** weekly: queries gaining impressions → make/strengthen
      the matching page.
- [ ] GSC **Links** report: watch referring domains grow.

## Realistic expectations

Backlinks and authority compound over **months**, not days. Directories +
social give an immediate base of links; guest posts and earned mentions are the
slower, higher-value layer. Pair every gain with the on-page work in
`docs/seo.md` (request indexing, keep content fresh) and watch GSC for the
queries to double down on.
